Qwen3.6-27B is a dense hybrid on the same mixer recipe as [[qwen3-5-397b-a17b]], without the MoE. Sixty-four layers repeat three [[gated-deltanet]] blocks then one gated [[gqa]] block, each with a SwiGLU feed-forward <Cite id="qwen3-6-27b-card" where="Hidden Layout" />. The blog's emphasis is coding agents and keeping a think span across turns; the architecture is the Qwen3.5 dense stack at 27B <Cite id="qwen3-6-blog" />.

The 3-then-1 layout is unchanged: 48 linear-attention layers and 16 full-attention layers (`full_attention_interval: 4`) <Cite id="qwen3-6-27b-config" where="text_config.layer_types" />. What this size drops is the expert pool, so every token pays for the whole feed-forward. Attention still uses QK-Norm, an output gate, and 25% partial M-RoPE, as in Qwen3.5 <Cite id="qwen3-5-modeling" where="Qwen3_5Attention" /> <Cite id="qwen3-6-27b-config" where="text_config.attn_output_gate, rope_parameters" />. [[mtp]] is trained with one extra block.

The checkpoint is also a vision-language model: a 27-layer ViT of width 1,152, the same tower shape as Qwen3.5, projects into hidden size 5,120 <Cite id="qwen3-6-27b-config" where="vision_config" />. Native context is 262,144 tokens, extensible to 1,010,000 <Cite id="qwen3-6-27b-card" where="Context Length" />.

## What it reuses

- [[gated-deltanet]] in 48 of 64 mixers, kernel 4.
- [[gqa]] with an output gate in the other 16.
- The [[qwen3-5-tokenizer]] 248K vocabulary, including vision and think specials.
