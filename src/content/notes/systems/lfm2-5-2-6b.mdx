LFM2.5-2.6B is [[lfm2-5-2-6b-base]] after agentic post-training. The 30-layer [[hybrid-conv-attention]] stack is the same 22 [[gated-short-conv]] plus 8 [[gqa]] layout; `layer_types` matches Base exactly <Cite id="lfm2-5-2-6b-config" where="layer_types" />. What is new is a four-stage pipeline that trains the model inside real agent harnesses, and a chat template that always thinks before it answers <Cite id="lfm2-5-2-6b-card" />.

## What is new

### Four-stage agent post-training

<Stepper title="Base to LFM2.5-2.6B">
  <Step title="Two rounds of SFT">
    Broad coverage first, then a second round that up-weights agentic tasks, reasoning and tool use. Across both rounds the SFT mix is about seven times the mix used for LFM2.5-8B-A1B, with more tool use, web search, software-engineering and agent traces.
  </Step>
  <Step title="Teacher specialization">
    From that SFT checkpoint, one specialist per domain is trained with a focused SFT round and then RL with verifiable rewards. The blog lists specialists for instruction following, math, knowledge including hallucination control, code, tool use, and long context.
  </Step>
  <Step title="Multi-domain on-policy distillation">
    The student rolls out under its own policy. Each prompt is routed to the matching teacher, which provides token-level feedback. Because the teachers branched from the same SFT checkpoint, the blog describes the supervision as close enough to the student's distribution to stay stable.
  </Step>
  <Step title="Agentic RL in real harnesses">
    Multi-turn GRPO runs inside unmodified harnesses (the blog names Hermes Agent and OpenClaw). A sandbox executes tools; an outcome reward mixes an LLM-as-judge rubric, programmatic checks and a hard safety gate. A harness proxy records token-level trajectories without changing the agent.
  </Step>
</Stepper>

A 328M speculative-decoding drafter (LFM2.5-2.6B-DSpark) is released with the weights; the card quotes about 2.6× faster decode with identical outputs <Cite id="lfm2-5-2-6b-card" />. The card recommends agentic workloads, tool use, extraction, RAG and long-context work, and not agentic coding or knowledge-heavy tasks <Cite id="lfm2-5-2-6b-card" />.

## What it reuses

- The [[lfm2-5-2-6b-base]] backbone: 30-layer [[hybrid-conv-attention]], 2048 hidden, 32/8 [[gqa]], kernel-3 [[gated-short-conv]], 128K vocab, 128K-class context.
- [[rope]] with θ $10^7$, as in Base.
