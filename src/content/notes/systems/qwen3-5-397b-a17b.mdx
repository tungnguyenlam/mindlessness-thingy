Qwen3.5-397B-A17B rebuilds [[qwen3-235b-a22b]] around a cheaper long context: most mixers are [[gated-deltanet]], whose state does not grow with $T$, and [[gqa]] appears only every fourth layer as a global anchor. The feed-forward is still [[moe]], now 512 experts with a shared one, and the checkpoint is a native vision-language model <Cite id="qwen3-5-397b-a17b-card" />. This note is that hybrid. [[minicpm-v-4-7-35b-a3b]] reuses the same language block at a smaller size.

## The whole model

Sixty layers in fifteen repeats of three Gated DeltaNet blocks then one gated-attention block, each followed by MoE <Cite id="qwen3-5-397b-a17b-card" where="Hidden Layout" />.

## What is new

### A Gated DeltaNet / GQA hybrid

The 45 linear-attention layers bound decode memory: each keeps $S_t \in \mathbb{R}^{64 \times 128 \times 128}$ and a kernel-4 conv buffer, independent of context length <Cite id="qwen3-5-397b-a17b-config" where="text_config.linear_num_value_heads, linear_key_head_dim, linear_conv_kernel_dim" />. How that state updates is in [[gated-deltanet]]. The 15 [[gqa]] layers still write a [[kv-cache]], but only every fourth layer, with 2 key/value heads of width 256 <Cite id="qwen3-5-397b-a17b-config" where="text_config.num_key_value_heads, head_dim" />.

Those attention layers also gate the output. `attn_output_gate: true` doubles the query projection so a sigmoid gate, conditioned on the current token, scales the attention output before $W_O$ <Cite id="qwen3-5-moe-modeling" where="Qwen3_5MoeAttention.forward" />. Partial [[rope]] rotates 64 of the 256 head dims ($\theta = 10^7$), interleaved as M-RoPE sections $[11, 11, 10]$ so image slices can share a canvas with text <Cite id="qwen3-5-397b-a17b-config" where="text_config.rope_parameters" />.

Qwen3 had dropped the shared expert. Qwen3.5 puts one back, gated by $\sigma(w^\top u_t)$, beside the ten routed experts <Cite id="qwen3-5-moe-modeling" where="Qwen3_5MoeSparseMoeBlock" />. Training also runs [[mtp]] with one extra block (`mtp_num_hidden_layers: 1`) <Cite id="qwen3-5-397b-a17b-config" where="text_config.mtp_num_hidden_layers" />.

The 397B / 17B counts on the card are the language model <Cite id="qwen3-5-397b-a17b-card" where="Language Model" />. A 27-layer ViT feeds the same hidden size through a [[vision-language-connector]]; this page follows the language stack. Native context is 256K in the config; the card says it extends to about 1M <Cite id="qwen3-5-397b-a17b-card" />.

## What it reuses

- [[gated-deltanet]] in 45 of 60 mixers, kernel 4.
- [[gqa]] with QK-Norm in the other 15, plus the output gate above.
- [[moe]] with a softmax top-k router.
- [[mtp]] as a one-block training head.
