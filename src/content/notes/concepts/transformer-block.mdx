A transformer model is one block, repeated: the original stacks six identical layers, each with two sub-layers <Cite id="attention-is-all-you-need" where="§3.1" />. The whole layer is one idea: run a sub-layer, add its output back onto the stream it was given, and do it twice. Everything a layer changes, it changes in the stream that flows past it.

## One forward pass

The layer takes the stream $x$, of shape $T \times d$. It normalizes each token's vector, runs [[mha]] across the sequence, and adds the result back to $x$. It normalizes again, runs the feed-forward network — two linear maps with a nonlinearity between them — and adds that back too <Cite id="attention-is-all-you-need" where="§3.1, §3.3" />. In the original the width is $d = 512$ and the feed-forward network widens it to $d_{ff} = 2048$ on the way through <Cite id="attention-is-all-you-need" where="§3.3" />.

Attention is the only place tokens exchange information; the feed-forward network touches each token on its own. During generation, the attention sub-layer is also the part that reads and extends the [[kv-cache]].

## Pre-norm or post-norm

The original paper adds first and normalizes after, writing each sub-layer as $\mathrm{LayerNorm}(x + \mathrm{Sublayer}(x))$ <Cite id="attention-is-all-you-need" where="§3.1" />. The diagram above draws the other order, normalize first, which leaves the residual stream itself unnormalized; models such as LFM2 are built this way <Cite id="lfm2-report" where="§2.2" />. Both orders carry the same tensors through the same maps. Only where the normalization sits changes.
