[[c-radio]] hands over one feature vector per image patch: a grid of $T$ vectors, each of width $d$. A language model reads tokens of its own width $d_L$, and every extra token adds attention and cache over the rest of the sequence. The connector is the small module in between. It merges neighbouring patches into fewer, wider tokens, then projects them with an MLP <Cite id="nemotron-3-nano-omni-report" where="§2" />.

The merge is a rearrange, not a computation: the features of neighbouring patches are stacked along the width axis, so nothing is thrown away yet. The MLP is the only learned part of the connector, mapping from the widened token into the language model's width <Cite id="nemotron-3-nano-omni-report" where="§2" />.

## Why merge before projecting

Dynamic resolution makes the count urgent: Nemotron's pipeline gives the encoder between 1,024 and 13,312 patches per image <Cite id="nemotron-3-nano-omni-report" where="§2" />. Every patch that survives into the language model costs attention against every other token and a slot in its [[kv-cache]]. The Omni report states the goal plainly: reduce the token count presented to the language model <Cite id="nemotron-3-nano-omni-report" where="§2" />.

## The numbers in Nemotron

The reports state the design but not every width. Omni uses 16×16 patches, at most 13,312 tokens per image, a pixel shuffle with 4× downsampling before the MLP projector, and a 3D convolution folding every two video frames into one <Cite id="nemotron-3-nano-omni-report" where="§2" />. Nemotron 3.5 Super VL publishes only two connector keys, consistent with the same design but not proof of it <Cite id="nemotron-3-5-super-vl-config" where="downsample_ratio, projector_hidden_size" />.

The MLP's depth and activation are unverified: the Omni report says only "MLP projectors", and Super VL's config gives no layer count.

## Where it sits

Nano Omni is an encoder–projector–decoder: C-RADIO encodes, the connector projects, and the visual tokens are concatenated with the text tokens into the one sequence the [[hybrid-ssm-attention]] backbone reads <Cite id="nemotron-3-nano-omni-report" where="§2" />. The projector is trained first and alone: the opening training stage freezes both encoders and the language model, and trains only the vision MLP projector <Cite id="nemotron-3-nano-omni-report" where="§3.1.1" />.

<Callout type="pitfall">
The merge is irreversible. Once neighbouring patches share one token, the language model can no longer attend to a single patch. Whether that costs fine detail such as small text is a per-model question; the Omni report does not ablate the merge factor.
</Callout>
